## 서비스 소개

PLAYUP은 함께 테니스를 칠 상대를 찾고, 일정을 조율하고, 코트를 확보하는 과정을 하나로 연결합니다.

내 조건에 맞는 매치를 추천받아 참가하고, 확보한 코트를 등록해 직접 매치를 개설할 수 있습니다.
이 저장소는 PLAYUP의 프론트엔드 프로젝트입니다.

## 주요 기능

현재 초기 개발 단계이며, 아래는 **MVP 기준 구현 예정 기능**입니다.

| 기능                  | 설명                                                                   |
| --------------------- | ---------------------------------------------------------------------- |
| 회원가입 · 프로필     | 가입·로그인, 기본 정보 및 테니스 프로필 등록·수정                      |
| 매치 추천 · 탐색      | 실력·지역·가능 시간에 따른 매치 추천, 날짜·시간·경기 유형 선택         |
| 매치 상세 · 참가      | 경기 정보·참가자·취소 정책 확인, 참가 신청·취소 및 상태 조회           |
| 코트 인증 · 매치 개설 | 예약 증빙 등록과 인증, 매치 개설, 승인 후 공개·모집                    |
| 입금 안내 · 참가 확정 | 계좌·금액·기한 안내, 운영자 수동 입금 확인 및 참가·매치 확정 상태 표시 |
| 내 매치 · 경기 안내   | 신청·참여 매치 조회, 경기 일정·시설·주차 안내, 참여 완료 상태 확인     |
| 알림                  | 신청·승인·거절·확정 및 취소·변경 안내                                  |
| 운영자 관리           | 코트·증빙 검수, 매치·참가자 관리, 수동 입금·환불·정산 이력 관리        |

> 랭킹·승급, 경기 결과 상호 인증, 후기·매너 평가, 클럽은 핵심 기능 구현 이후 검토하는 추가 기능입니다.
